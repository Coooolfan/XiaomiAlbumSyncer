# Overview

Xiaomi Album Syncer is a self-hosted tool that downloads albums and recordings from Xiaomi Cloud to local storage — **full / incremental / scheduled**.

## Core capabilities

- **Full & incremental download**: pulls the entire library on first run, then syncs incrementally, skipping assets already downloaded.
- **Scheduled tasks**: schedule syncs with crontab expressions, with manual triggers and execution history replay.
- **Albums & recordings**: in addition to album assets, recordings stored in Xiaomi Cloud are supported too.
- **Multi-account**: bind multiple Xiaomi accounts with QR-code login and automatic cookie refresh.
