# Overview

Xiaomi Album Syncer (XAS) is a self-hosted cloud album backup and synchronization tool designed to download albums, videos, and audio recordings from **Xiaomi Cloud** and **Apple iCloud** to local storage or NAS through **full / incremental / scheduled** pipelines.

![Task schedule and activity heatmap](/screenshots/en-US/schedule-overview.avif)

## Core Capabilities

- **Multi-Cloud Provider Support**: Bind multiple Xiaomi accounts (QR code login with automatic session refresh) and Apple accounts (mainland China and global endpoints, 2FA trusted device verification) in one unified dashboard.
- **Full & Incremental Synchronization**: Perform initial full archive of cloud libraries, followed by lightning-fast **cursor incremental (CURSOR)** or **timeline incremental (TIMELINE)** synchronization, automatically skipping downloaded assets.
- **Original Media Downloads**:
  - Download full-resolution photos and videos, supporting secondary originals and RAW+JPEG pairs.
  - Full support for Apple **Live Photo** assets (downloading high-res still image alongside companion `.mov` video).
  - Download Xiaomi Cloud voice recordings categorized into call recordings, voice memos, etc.
- **Flexible Scheduling & History**: High-precision Cron scheduler with second-level accuracy, detailed historical logs, and error retry replays.
- **Custom Destination Path Expressions**: Organize files using expressive variables like `${album}`, `${taken_yyyy-MM-dd}`, `${checksum}`, and `${assetId}`.
- **EXIF & File System Timestamps**: Automatically restore capture time into photo EXIF metadata and host file system creation/modification times.
- **Modern & Secure Architecture**: Clean responsive Web UI, Passkey (WebAuthn) passwordless authentication, and native SSL/HTTPS.
- **AI & Automation Ecosystem**: Built-in **MCP (Model Context Protocol)** server to query status or trigger backups from AI assistants like Claude Desktop and Cursor; configurable Webhook notifications.
