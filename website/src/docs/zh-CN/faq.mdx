# 常见问题

## 1. 登录与账号凭据

### 小米账号登录态能维持多久？
扫码登录后，后端会使用 PassToken 自动向小米服务器刷新和续期 Cookie。只要账号未在其他设备被强制登出或修改密码，通常可长期维持有效。如果凭据失效，页面会提示重新扫码，并可触发 WebHook 告警。

### iCloud 登录提示 409 或认证失败？
请检查以下两项 Apple ID 设置：
1. **高级数据保护 (ADP)**：必须在 Apple 设备设置中关闭「高级数据保护」。
2. **网页数据访问**：必须开启「在网页上访问 iCloud 数据」。
此外，请检查所选区域端点（中国大陆选 `icloud.com.cn`，其他国家/地区选 `icloud.com`）。

### 忘记管理员登录密码怎么办？
管理员密码保存在本地 SQLite 数据库中。清空 `system_config` 表即可重置：
```bash
sqlite3 /path/to/db/xiaomialbumsyncer.db "DELETE FROM system_config;"
```
清空后刷新网页，系统会自动进入「初始化 / 设置新密码」流程。

## 2. 同步与下载

### 增量同步是如何判断已存在文件的？
系统在数据库中记录已下载资产的唯一特征（对于小米为远端资产 ID 与 SHA-1，对于 iCloud 为 remoteKey 与 checksum）。若任务开启了「跳过已存在文件」，后续执行时若目标路径已有同名文件且记录匹配，会直接跳过下载。

### Apple Live Photo（实况照片）是如何保存的？
XAS 会同时下载高分辨率静态图片（如 `.HEIC` 或 `.JPG`）与配套的原始动态视频文件（`.MOV`），两者具有相同的主文件名。将它们导入 Immich、群晖 Photos 或 Apple Photos 时，相册应用会自动合并渲染为实况照片。

### 下载的照片拍摄时间不对？
如果相册软件显示照片时间变成了下载当天的时间：
- 请确保任务开启了**「回填 EXIF 拍摄时间」**与**「回填文件系统时间」**。
- 检查任务设置中的「时区（Time Zone）」配置是否符合您所在的本地时区（例如 `Asia/Shanghai`）。

### 定时任务为什么没有在预定时间触发？
XAS 调度器基于 Solon Cron，采用带秒级的 **6 段或 7 段 Cron 表达式**（例如每日凌晨 3 点应写为 `0 0 3 * * ?`，而非标准的 5 段 Linux crontab `0 3 * * *`）。请确认格式是否满足规范，并检查容器或主机的系统时区配置。

## 3. 存储与网络

### 录音文件保存在哪里？如何避免重名覆盖？
录音文件与相册资产共享任务的目标根路径。默认规则下录音会自动拼接 `{assetId}_{fileName}` 避免覆盖。您也可以在「下载路径表达式」中使用 `${recordingType}` 变量按分类存放（如 `${recordingType}/${fileName}`）。

### 能否通过 Nginx 或反向代理对外提供服务？
可以。请确保在反向代理中配置了正确的 Host 头，并且生产环境务必开启 HTTPS（Passkey 依赖安全上下文生效）。对于 `/mcp` 接口，若启用了反向代理，建议关闭缓冲（如 Nginx 的 `proxy_buffering off;`）以支持 SSE 流式传输。
