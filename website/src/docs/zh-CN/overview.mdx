# 概览

Xiaomi Album Syncer（简称 XAS）是一个自部署云相册备份与同步工具，用于把**小米云服务**和 **Apple iCloud** 中的相册、视频与录音**全量 / 增量 / 定时**下载到本地存储或 NAS。

![任务调度与运行热力图](/screenshots/zh-CN/schedule-overview.avif)

## 核心能力

- **多云服务支持**：支持绑定多个小米账号（扫码登录、Cookie 自动续期）与 Apple 账号（支持中国大陆与国际端点、两步验证 2FA），统一管理。
- **全量与增量同步**：支持首次全量归档相册资产；后续可通过**位点增量（CURSOR）**或**时间线增量（TIMELINE）**高效拉取新资产，自动跳过已下载内容。
- **多媒体原件下载**：
  - 相册照片与视频（保留原始质量，支持备用原件与 RAW+JPEG 配对）。
  - 支持 Apple **Live Photo** 动态照片（原件图片及配套 `.mov` 视频合并同步）。
  - 支持下载小米云服务中的录音文件，并识别录音分类。
- **定时调度与历史回放**：基于带秒级的高精度 Cron 表达式灵活调度任务，记录详细运行历史并支持状态回放与失败重试。
- **灵活的路径模板**：支持 `${album}`、`${taken_yyyy-MM-dd}`、`${checksum}` 等丰富变量，随心自定义归档层级与文件名。
- **元数据与时间回填**：自动将拍摄时间写入照片的 EXIF 信息与宿主机文件系统的创建/修改时间。
- **现代化与安全架构**：提供简洁响应式 Web UI、Passkey（WebAuthn）生物识别免密登录、原生 SSL/HTTPS 支持。
- **AI 与自动化生态**：内置 **MCP（Model Context Protocol）** 服务，可无缝接入 Claude Desktop、Cursor 等 AI 助手查询状态或调度任务；支持自定义 Webhook 任务通知。
