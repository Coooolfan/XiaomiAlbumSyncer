# 概览

Xiaomi Album Syncer 是一个自部署工具，用于把小米云服务中的相册与录音**全量 / 增量 / 定时**下载到本地存储。

## 核心能力

- **全量与增量下载**：首次全量拉取相册，之后增量同步，自动跳过已下载的资产。
- **定时任务**：通过 Crontab 表达式调度同步计划，支持手动触发与执行历史回放。
- **相册与录音**：除相册资产外，同时支持下载小米云服务中的录音文件。
- **多账号**：支持绑定多个小米账号，扫码登录，Cookie 自动刷新续期。
