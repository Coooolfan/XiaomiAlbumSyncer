> [!IMPORTANT]
> iCloud 同步要求启用网页数据访问并关闭高级数据保护（ADP），不支持最近删除和「共享相册」服务
> iCloud 协议测试使用本地模拟服务，尚未验证真实 Apple 账号的权限和私有接口兼容性
> 此版本包含数据库结构变更，程序会自动迁移已有账号、相册和资产，并保留下载历史的本地 ID
