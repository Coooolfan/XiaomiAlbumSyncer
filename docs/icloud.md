# iCloud 相册同步

在设置的「同步账号」中添加 Apple iCloud 账号，填写 Apple 账号、账号密码和区域。国际账号选择 `icloud.com`，中国大陆账号选择 `icloud.com.cn`。Apple 要求双重认证时，输入受信任设备显示的六位验证码。关闭弹窗后，可以通过账号的编辑按钮继续认证。

## 账号条件

- 已启用 iCloud 照片，并允许在网页上访问 iCloud 数据。
- 关闭 iCloud 高级数据保护（ADP）。当前后台同步不支持受信任设备临时授权的 ADP 网页访问。
- 账号能够完成 Apple 的 SRP 登录和受信任设备双重认证；不支持应用专用密码、扫码登录、传统 2SA 或短信验证码登录。
- 照片索引状态为 `FINISHED`；尚未完成时会提示稍后重试。

## 同步内容

支持个人图库，以及接口返回的 `SharedSync-*` 共享图库区域中的照片和视频。可选择所有照片、隐藏、个人收藏和用户相册。iCloud「共享相册」是另一种服务，不在此范围内。

下载原始照片和视频，同时保存 Live Photo 的原始照片与视频，以及 RAW+JPEG 的两个原始文件。不下载编辑后的渲染版本和编辑 sidecar。文件名附加稳定资源标识，避免同名文件互相覆盖。一个照片属于多个相册时，每个相册保留独立的下载记录和目录。小米远端资产 ID 与本地 ID 分别保存；已有数据的本地 ID 保持不变，跨来源 ID 冲突时为新资源分配独立的本地 ID。

任务支持全量和位点增量两种模式，不支持时间线比较。全量模式每次枚举所选相册；位点模式使用 CloudKit `syncToken` 从上次位置读取图库变化，首次同步、所选相册范围变更或位点失效时自动全量建立基线。位点按任务、图库与所选相册范围隔离，保存在任务历史的游标 JSON 中，与登录凭据无关。每页资产成功落库后提交位点，下载失败由本地待处理资产和历史继续重试。删除和移出相册事件不会删除已有备份；更新记录可补充新增的原件资源。下载阶段检查文件大小；SHA-1 校验仅在任务开启校验选项时，由校验阶段执行。「跳过已有文件」选项直接复用已有文件，之后按任务配置处理校验。下载地址按需获取，不写入数据库。

## 重新认证与通知

会话失效时，后台使用保存的密码和信任令牌重新登录；Apple 要求验证码时，账号状态变为「需要验证码」。点击账号编辑按钮输入验证码，或重新登录后，下一次同步继续处理未完成资源。认证有效期由 Apple 决定，不承诺固定的 30 天周期。

通知配置中的「账号认证失效通知模板」适用于小米和 iCloud。模板留空时不发送通知；配置后，同一认证失效状态只提醒一次，认证成功后恢复提醒能力。数据库字段 `passTokenExpiredBody` 保持兼容。

## 凭据与备份

所有云服务账号存放在 `provider_account` 表中，`provider` 标识来源，`credentials` 是 JSON 文本列。小米账号保存 `passToken`；iCloud 账号保存 Apple ID、密码、区域、客户端标识、认证 headers、cookies 和认证状态。小米的短期 `serviceToken` 仍只保存在内存；iCloud 的 CloudKit 地址、下载地址和校验结果不写入凭据列。账号列表、登录响应和生成的前端 API 不返回凭据。

凭据直接以 JSON 明文保存在数据库中，备份仅需数据库，无需密钥文件。应限制数据库及备份的访问权限。

## 开发验证

认证使用 Kotlin 实现的 SRP-6a、SHA-256 和 Apple `s2k` / `s2k_fo` 密码派生。HTTP cookie 按账号隔离，Apple 认证头不发送给下载 CDN。协议参考及原始许可证见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

测试覆盖 SRP 与 pysrp 固定向量的互操作、双重认证、持久化会话恢复、区域端点、Live Photo / RAW+JPEG 资源映射、相册成员隔离、变更流分页与位点恢复、保存失败时不推进位点、文件校验以及旧数据库升级。真实 Apple 账号的登录、图库权限与私有接口兼容性仍需在实际账号上验证。
